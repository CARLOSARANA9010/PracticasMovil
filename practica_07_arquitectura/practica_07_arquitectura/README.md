# Práctica 7 - Arquitectura, Componentes y Optimización

## Objetivo
Estructurar una aplicación Flutter escalable, integrar paquetes externos (`provider`, `intl`) y aplicar prácticas básicas de rendimiento separando responsabilidades.

## Requisitos
* Flutter SDK (versión estable actual).
* Dispositivo físico o emulador.
* Paquetes: `provider`, `intl`.

## Instalación
1. Clonar el repositorio.
2. Posicionarse en la rama `practica-07-arquitectura`.
3. Ejecutar `flutter pub get` para descargar dependencias.

## Ejecución
1. Conectar dispositivo o levantar emulador.
2. Ejecutar `flutter run`.
3. Para verificar calidad de código, ejecutar `flutter analyze`.
4. Para correr pruebas unitarias, ejecutar `flutter test`.
